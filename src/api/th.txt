HTTP Methods 
------------
1. GET    -- backend to frontend 
2. POST   -- frontend to backend (new data/INFORMATION)
3. PUT    -- id (101) [complete user update]
4. PATCH  -- id (101) [partial user update]
5. DELETE -- id (101) [delete this user from database]
